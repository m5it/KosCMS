FILE I/O TOOLS (5):
- ReadFile: Get file content. Params: fileName (required)
- WriteFile: Create/overwrite file. Params: fileName, contentOfFile (required)
- CreateFile: Create empty file. Params: fileName (required), contentOfFile (optional)
- AppendFile: Append to file. Params: fileName, content (required)
- ReplaceLine: Replace line range. Params: fileName, fromLine, toLine, replacement (required)

DIRECTORY TOOLS (3):
- List: List files/dirs. Params: path (optional, default current)
- TreeView: ASCII tree. Params: depth (optional), showFiles (optional)

SEARCH TOOLS (2):
- Grep: Regex search. Params: pattern, fileName, recursive (required)
- Sed: Stream editor. Params: pattern, replacement, fileName, inplace (required)

EDITING TOOLS (4):
- Diff: Compare files. Params: file1, file2, unified (required)
- Head: First N lines. Params: fileName, lines (required)
- Tail: Last N lines. Params: fileName, lines (required)
- Sort: Sort lines. Params: fileName, reverse, unique (required)

EXECUTION TOOLS (2):

WEB TOOLS (2):
